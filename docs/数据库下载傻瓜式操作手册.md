## 二、开始前只做这 5 件事

### 第 1 步：打开正确的项目文件夹

在 Finder 中依次打开：

```text
文稿/Documents
→ ChatGPT
→ Investment
→ A share investment
→ data
→ raw
```

`raw` 下面已经写好了保存规则。每个数据库单独放一个文件夹，例如 `CSMAR`、`WIND`、`CNRDS`。

### 第 2 步：如果人在校外，先退出清华 VPN

使用清华图书馆“智能网关”或“校外访问控制系统”时，先断开清华 VPN。清华图书馆的校外访问说明明确提示，两者和清华 VPN 同时使用可能出错。

### 第 3 步：总是从清华图书馆的数据库入口进入

不要先在百度搜索数据库官网。正确顺序是：

1. 打开[清华大学图书馆数据库导航](https://ecollection.lib.tsinghua.edu.cn/databasenav/)。
2. 在搜索框输入数据库名字，例如 `CSMAR`。
3. 点击数据库名称，进入该库的“说明页”。
4. 在说明页找 **“访问入口”**，从这里进入供应商网站。
5. 如果你在校外，页面会跳到清华统一身份认证。
6. 输入自己的清华账号，完成短信或微信双因素验证。
7. 进入供应商页面后，确认页面出现“机构用户”“学校登录”“清华大学”或已购数据库，而不是只显示试用数据。

清华智能网关会根据 IP 自动判断校内或校外；校外会先做统一身份认证。不同数据库支持的校外方式不完全一样，以各数据库说明页为准。

### 第 4 步：建立一个“下载说明”文本

每一批下载都要记住 7 件事：

```text
数据库：
数据表名称：
下载日期：
查询日期范围：
股票范围：
选择字段：
页面显示的单位、复权和缺失值说明：
```

最简单的做法：在原始数据文件旁边新建一个同名文本，例如：

```text
CSMAR_TRD_Dalyr_SAMPLE_202401.csv
CSMAR_TRD_Dalyr_SAMPLE_202401__说明.txt
```

### 第 5 步：不要让 Excel 破坏股票代码

股票代码 `000001` 很容易被 Excel 变成 `1`。因此：

1. 原始 CSV 下载后不要直接双击、修改并保存。
2. 要查看时，可以只预览，不保存。
3. 如果必须用 Excel 导入，使用“数据 → 从文本/CSV”，把股票代码列设为“文本”。
4. 原始 ZIP 和原始 CSV 都保留。

## 四、先做一遍：CSMAR 日行情小样本

这是最适合第一次练习的下载。

### 4.1 进入 CSMAR

1. 打开[清华 CSMAR 数据库说明页](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021498916503966)。
2. 点击 **“访问入口”**。
3. 如果出现清华登录页，完成统一身份认证和双因素验证。
4. 进入 CSMAR 后找 **“数据中心”**。
5. 如果页面要求登录个人账号，先找“机构登录”“IP 登录”或“学校登录”。仍不能下载时，再用清华邮箱注册个人账号。
6. CSMAR 中已购买/可下载的库通常正常显示；灰色或标有未购买的表不能下载。不要付费开通个人试用，先确认学校权限。

### 4.2 找到正确的数据表

1. 在数据中心的字段/表搜索框输入：

```text
日个股回报率文件
```

2. 在搜索结果中点击 **表结果**，优先选择：

```text
股票市场系列
→ 股票市场交易
→ 日个股回报率文件
```

3. 如果名称略有不同，选同时包含“日”“个股”“回报率/行情”的表。
4. 打开后，先点击 **“字段说明和样本数据”**。
5. 确认这张表是一只股票、一个交易日一行，而不是一只股票、一个月一行。

### 4.3 设置样本日期

在“时间设置”中选择自定义范围：

```text
开始：2024-01-02
结束：2024-01-31
```

如果页面只接受年月日数字，就填 `20240102` 和 `20240131`。

### 4.4 设置 5 只样本股票

在“代码设置”选择 **“代码选择”**，输入下面这行：

```text
000001,000002,600000,600519,300750
```

CSMAR 多个代码之间使用**半角逗号**，也就是英文逗号 `,`。不要用中文逗号 `，`。

如果手工输入不好用：

1. 点击 **“代码筛选”**。
2. 分别搜索 5 个代码。
3. 把它们从“可选代码”移到“已选代码”。
4. 确认右侧正好是 5 只。

### 4.5 勾选字段

在“字段选择”中，用字段搜索逐个找下面这些中文含义。括号内是 CSMAR 常见英文缩写，页面版本不同可以没有这些缩写。

- 股票代码（常见 `Stkcd`）
- 交易日期（常见 `Trddt`）
- 开盘价（常见 `Opnprc`）
- 最高价（常见 `Hiprc`）
- 最低价（常见 `Loprc`）
- 收盘价（常见 `Clsprc`）
- 交易股数/成交量（常见 `Dnshrtrd`）
- 交易金额/成交额（常见 `Dnvaltrd`）
- 流通市值（常见 `Dsmvosd`）
- 总市值（常见 `Dsmvtll`）
- 考虑现金红利再投资的日回报率（常见 `Dretwd`）
- 不考虑现金红利的日回报率（常见 `Dretnd`）
- 可比价格或复权相关字段（如果本表提供）
- 市场类型（常见 `Markettype`）
- 交易状态（常见 `Trdsta`）

每个字段都把鼠标移上去或点击“字段说明”，检查单位。特别记录：

- 成交量是“股”还是“手”；
- 成交额是“元”还是“千元”；
- 市值是“元”“千元”还是“万元”；
- 回报率是小数还是百分数；
- 价格是否未复权。

不要因为英文代码不同就随便选相似字段。找不到时，在说明文件中写“缺失”，后面由 Wind/RESSET 补齐。

### 4.6 预览和下载

1. 条件筛选先留空。
2. 点击 **“预览数据”**。CSMAR 通常只展示前 1000 行，这是正常的。
3. 预览中确认：有 5 个股票代码、日期是 2024 年 1 月、价格看起来不是空白。
4. 下载格式选 **CSV**。
5. 缺失值处理选 **“不填充”**。绝对不要选向前填充或向后填充。
6. 点击 **“提交查询”**。
7. 新页面出现“下载概要”后，再检查一次代码、日期和字段。
8. 下载 ZIP 文件。CSMAR 的下载链接通常只保留 48 小时，所以立即保存到本机。
9. 解压 ZIP，但原 ZIP 不要删除。

把文件改名为：

```text
CSMAR_TRD_Dalyr_SAMPLE_202401.csv
```

保存到：

```text
data/raw/CSMAR/SAMPLE/
```

### 4.7 下载后 30 秒检查

只检查，不修改原文件：

- 股票代码仍然是 `000001`，不是 `1`；
- 日期覆盖 2024-01-02 到 2024-01-31；
- 大约有 5 × 当月交易日数的记录；
- 开高低收四列存在；
- 成交量和成交额不是同一个数量级；
- 文件旁边有字段说明或数据字典。

## 五、CSMAR 全量日行情怎么下

样本确认无误后再做。

### 5.1 股票范围怎么选

最稳妥的选法是下载**全部沪深 A 股历史数据**，以后用历史沪深300成分表筛选。这样可以避免只下载今天的300只股票造成幸存者偏差。

在代码设置里：

1. 选择 **“全部代码”**；或者在“代码筛选”里选沪深 A 股。
2. 不要勾选“当前上市”“正常上市”之类只保留今天存续股票的条件。
3. 要保留已退市、曾暂停上市、曾 ST 的股票。
4. 如果表中同时有 A/B 股，用“市场类型”或“证券类型”筛选沪深 A 股；不确定时先全下，后续再按数据字典筛选。

### 5.2 日期和分文件方法

从 `2009-01-01` 开始，每年下载一个文件。不要一次提交 17 年数据。

文件命名示例：

```text
CSMAR_TRD_Dalyr_2009.csv
CSMAR_TRD_Dalyr_2010.csv
...
CSMAR_TRD_Dalyr_2026.csv
```

每一年都用与样本完全相同的字段、相同的单位、相同的缺失值设置。可以在 CSMAR 勾选“保存方案”，命名：

```text
Ashare_Daily_Full_v1
```

下一年调用这个方案，只改日期。

### 5.3 遇到下载条数上限

如果系统提示超过上限：

1. 不要连续狂点下载。
2. 先把一年拆成上半年和下半年。
3. 仍超限，再按季度拆分。
4. 如果必须产生几十个任务，使用 CSMAR 自带的批量/数据服务渠道或联系在线客服，说明是学校授权的学术研究。
5. 不要写脚本自动点击网页。清华数据库使用规范不允许用网络下载工具进行系统性抓取；大批量需求应走数据库提供的正式批量导出或由馆员协调。

## 六、CSMAR 三张财务报表怎么下

财务数据不能只拿今天看到的 TTM 指标。我们需要报告期、实际披露时间和历史修订版本。

### 6.1 资产负债表样本

1. 回到 **“数据中心”**。
2. 搜索：

```text
资产负债表
```

3. 选择上市公司财务报表中的资产负债表。
4. 报表类型选择 **“合并报表”**。不要选母公司报表。
5. 日期选择 `2022-01-01` 到 `2024-12-31`。
6. 代码输入：

```text
000001,000002,600000,600519,300750
```

7. 字段至少选择：

- 股票代码
- 报告期/会计期间
- 报表类型
- 货币资金
- 总资产
- 总负债
- 股东权益合计
- 归属于母公司所有者权益
- 数据来源、更新日期或版本标识（如果提供）

8. 缺失值选择“不填充”，格式选 CSV。
9. 预览后提交并下载。
10. 文件名：

```text
CSMAR_FS_Balance_SAMPLE_2022_2024.csv
```

### 6.2 利润表样本

重复同样操作，搜索：

```text

```

至少选择：

- 股票代码
- 报告期/会计期间
- 报表类型

- 营业成本
- 营业利润
- 利润总额
- 净利润
- 归属于母公司所有者的净利润
- 数据来源、更新日期或版本标识（如果提供）

文件名：

```text
CSMAR_FS_Income_SAMPLE_2022_2024.csv
```

### 6.3 现金流量表样本

重复同样操作，搜索：

```text
现金流量表
```

至少选择：

- 股票代码
- 报告期/会计期间
- 报表类型
- 经营活动现金流入小计
- 经营活动现金流出小计
- 经营活动产生的现金流量净额
- 投资活动产生的现金流量净额

- 数据来源、更新日期或版本标识（如果提供）


### 6.4 可选升级：“实际披露日期”

第一版已经用“法定披露截止日次日”作为保守可用时间，不需要继续找这一张表。该方法不会提前看到财报，只会比真实披露时间晚。如果以后想提高基本面信号时效，再按下面步骤补实际披露日。

在数据中心依次搜索下面几个词，选择能明确对应证券和报告期的表：

```text
财务报告披露日期
实际披露日期
定期报告披露日期
财务报表公布日期
```

选择字段：

- 股票代码
- 报告期
- 报告类型
- 实际披露日期
- 实际披露时间（如有）
- 首次披露日期
- 更正/修订日期
- 公告 ID 或报告 ID

文件名：

```text
CSMAR_Financial_Disclosure_SAMPLE_2022_2024.csv
```

如果完全找不到这张表，把三张报表先下载下来，并在说明中写“缺披露日”。不要把报告期当披露日。

### 6.5 财务全量

样本确认后：

- 日期从 2008-01-01 到最新；
- 全部沪深 A 股，包含退市公司；
- 合并报表；
- 三张报表分别下载；
- 披露日期表单独下载；
- 不填充缺失值；
- 原始版本和更正版本都保留；
- 数据太大时按 5 年一个文件拆分。

文件名示例：

```text
CSMAR_FS_Balance_2008_2012.csv
CSMAR_FS_Income_2008_2012.csv
CSMAR_FS_Cashflow_2008_2012.csv
CSMAR_Financial_Disclosure_2008_2012.csv
```

## 八、Wind：历史沪深300成分、状态和基准怎么下

Wind 是这一套数据里最可能需要去金融图书馆终端操作的部分。

### 8.1 先确认怎么使用终端

1. 查看[清华金融图书馆数据库列表](https://lib.tsinghua.edu.cn/finance/info/1122/1235.htm)。
2. Wind 条目当前提示金融学院师生联系图书馆老师，电话 `62773530`。
3. 金融图书馆咨询台公开联系方式为 `010-62772511`。如果前一个电话无人接，打咨询台。
4. 可以直接照下面这段话说：

```text
老师您好，我是清华学生，想用 Wind 做非商业学术研究。
我需要导出 2009 年至今的沪深300历史成分、成分权重、纳入和剔除日期，
以及沪深300价格指数和全收益指数。请问应使用哪台终端，是否需要预约，
基础终端是否支持历史批量导出？
```

5. 到馆后，在指定 Windows 电脑上登录校园网和图书馆提供的 Wind 权限。不要在自己电脑上随便安装个人试用版替代学校权限。

### 8.2 认识 Wind 的操作方法

打开 Wind 终端后：

1. 点击顶部搜索框。
2. 输入 `EDE`，按回车，进入股票数据浏览器。部分版本也可以搜索“数据浏览器”。
3. Wind 培训中把 EDE 操作概括为 **“三选一提”**：
   - 选范围；
   - 选指标；
   - 选参数；
   - 提取数据。
4. 如果 EDE 找不到某个指标，打开 Excel，在 Wind 插件中点 **“函数搜索”** 或 **“辅助功能”**，用中文搜索指标。学校页面显示基础终端未必购买量化/API权限，因此第一版按图形界面和 Excel 插件操作，不依赖 Python API。

### 8.3 先下一个历史成分样本

在 Wind 顶部搜索框或 EDE 指标搜索中依次尝试：

```text
沪深300 成分股
指数成分股
指数成分及权重
历史成分股
```

设置：

```text
指数：沪深300
指数代码：在结果中选择明确标为沪深300的代码
样本日期：2024-01-31
```

选择字段：

- 成分证券代码
- 成分证券名称
- 交易所
- 指数权重
- 自由流通市值或计算权重用市值（如有）
- 数据日期

点击“提取数据”或“导出到 Excel”，保存为：

```text
WIND_CSI300_CONSTITUENTS_SAMPLE_20240131.xlsx
```

检查：应当接近 300 只，权重合计接近 100% 或 1。把页面显示的权重单位记在说明文件中。

### 8.4 下载历史成分变更

继续搜索：

```text
沪深300 历史成分
指数成分调整
纳入日期
剔除日期
```

目标是得到一行一次成员关系，至少包含：

- 指数代码/名称
- 股票代码/名称
- 纳入日期
- 剔除日期
- 纳入公告日期
- 剔除公告日期
- 数据更新时间

日期范围优先从沪深300发布以来到最新，最低要求是 2009 年至今。文件名：

```text
WIND_CSI300_MEMBERSHIP_HISTORY_2005_2026.xlsx
```

如果结果只有今天的 300 只，没有纳入/剔除日期，这不是历史成分表，不能使用。

### 8.5 下载逐日成分权重

理想文件是一只成分股、一个交易日一行：日期、代码、当日权重。

设置：

```text
指数：沪深300
开始：2009-01-01
结束：最新日期
频率：日
指标：成分及权重
```

日度成分权重会超过单个 Excel 工作表的行数上限，应按 5 年或更短区间拆分保存：

```text
WIND_CSI300_DAILY_WEIGHTS_2009_2013.xlsx
WIND_CSI300_DAILY_WEIGHTS_2014_2018.xlsx
WIND_CSI300_DAILY_WEIGHTS_2019_2023.xlsx
WIND_CSI300_DAILY_WEIGHTS_2024_2026.xlsx
```

很多 Wind 界面只允许选一个截面日期。如果你看到这种情况，**不要手工点击几千个交易日**。直接向馆员或 Wind 客服提出正式批量导出请求：

```text
我需要沪深300从2009年至今的历史日度成分和权重，
字段为交易日、指数代码、成分证券代码、成分权重、数据可知/更新时间。
当前界面似乎只能导出单日截面。请问学校授权下是否有历史批量表、Excel函数、
数据浏览器方案或由数据服务人员导出的方式？
```

只拿到“成员区间”也先保存；后续可以展开为逐日成员。权重数据缺失时要单独标记，不能假装是官方权重。

### 8.6 下载沪深300价格指数和全收益指数

在 Wind 搜索：

```text
沪深300 指数日行情
沪深300 全收益指数
```

不要凭记忆手输全收益指数代码。请在搜索结果中选择名称明确带“全收益”的指数。

日期：2009-01-01 至最新。频率：日。字段：

- 交易日期
- 开盘、最高、最低、收盘
- 昨收盘
- 涨跌幅
- 成交量、成交额（价格指数如有）
- 指数名称和代码

分别保存：

```text
WIND_CSI300_PRICE_INDEX_DAILY_2009_2026.xlsx
WIND_CSI300_TOTAL_RETURN_INDEX_DAILY_2009_2026.xlsx
```

价格指数和全收益指数不能混成一列，也不能用价格指数假装全收益指数。

### 8.7 下载交易状态和证券属性

在 EDE/函数搜索中依次搜索：

```text
交易状态
停牌
风险警示 ST
上市日期
退市日期
涨停价
跌停价
申万一级行业
历史行业
```

范围用“历史上曾进入沪深300的全部股票”，日期 2009 年至今。历史行业必须带生效日期或逐日值；今天的行业分类不能直接回填到过去。

如果这些字段可在日行情表中按日提取，放同一个文件；否则分表保存。日度文件按年份或 5 年以内的区间拆分，避免超过 Excel 行数上限。文件名示例：

```text
WIND_SECURITY_STATUS_DAILY_2009_2013.xlsx
WIND_INDUSTRY_HISTORY_2009_2013.xlsx
WIND_TRADING_CALENDAR_2009_2027.xlsx
```

交易日历要额外包含未来至少 10 个交易日；工作日不是交易日。

## 九、RESSET：当 CSMAR 缺字段时怎么补

RESSET 第一版主要有两个用途：核对 CSMAR，或者补 CSMAR 无法提供的字段。先不要把相同的全量数据重复下载两遍。

### 9.1 进入 RESSET

1. 打开[清华 RESSET 金融研究数据库说明页](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021702838403966)。
2. 点击“访问入口”。
3. 也可以在学校权限确认后访问 `db.resset.com`。
4. RESSET 支持校园 IP、学校邮箱账号和部分学校 CARSI 登录。优先从清华入口进入。
5. 首页黑色并带可用标识的数据库可以下载；灰色通常只能看，不能下载。

### 9.2 下载同一份 5 股票日行情样本

1. 首页搜索框输入：

```text
日股票综合数据
```

2. 找不到时进入：

```text
金融系列
→ RESSET股票
```

3. 选择包含每日开高低收、成交量额和市值的日度综合表。
4. 先点“数据样例”和“数据词典”。
5. 第 1 步日期范围：`2024-01-02` 至 `2024-01-31`。
6. 第 2 步查询条件选择“普通查询”，查询对象选“股票代码”。
7. 输入：

```text
000001 000002 600000 600519 300750
```

注意：RESSET 多个股票代码用**空格**分隔，不是逗号。

8. 也可以点“代码选择”，把代码移到右侧已选框。代码很多时，可上传 TXT；每行一个代码或同一行用空格分隔。
9. 第 3 步选择输出字段：代码、日期、开高低收、昨收、成交量、成交额、复权因子/可比价、流通市值、总市值、换手率、交易状态。
10. 第 4 步输出格式选 **“逗号分隔文本（*.csv）”**，压缩选 ZIP。
11. 先点“数据预览”。RESSET 手册中的预览只显示 15 条，这是正常的。
12. 点击“下载数据”，保存数据文件和数据词典。

文件名：

```text
RESSET_DAILY_SAMPLE_202401.csv
RESSET_DAILY_SAMPLE_202401__数据词典.pdf
```

### 9.3 和 CSMAR 对账

只比较 5 只股票：

- 交易日期数量是否一致；
- 未复权收盘价是否一致；
- 成交量单位是股还是手；
- 成交额单位；
- 总市值/流通市值单位；
- 停牌日是否保留；
- 复权口径是否相同。

如果一致，日行情以 CSMAR 为主，RESSET 文件作为核对证据。如果 CSMAR 缺交易状态、涨跌停价或复权因子，再从 RESSET 下载对应全量表。

### 9.4 下载上限和链接

RESSET 不同学校权限的单次上限不同。输出设置里先看“下载最大行数”；超过时按年或季度拆分。下载链接通常只保存 48 小时，应立即保存。大批量数据走平台正式下载功能或咨询反馈，不要自动抓网页。

## 十、CNRDS：新闻和股吧怎么下

### 10.1 进入 CNRDS

1. 打开[清华 CNRDS 说明页](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021558927303966)。
2. 点击“访问入口”。
3. 进入后优先点 **“学校登录”** 或机构登录。
4. 如果基础库能看但特色库不能下载，尝试用清华邮箱注册个人账号，再从校园 IP/智能网关进入。
5. 页面显示未订阅时，不要购买个人套餐；先问图书馆清华订购的“新闻、股吧、社交媒体”模块是否需要绑定个人账号。

### 10.2 下载新闻小样本

1. 顶部搜索框输入：

```text
中国上市公司财经新闻数据库
```

2. 选择常见简称带 `CFND` 的数据库。
3. 在“数据库—模块—表格”导航中，先选：

```text
网络财经新闻
→ 网络财经新闻基本信息
```

4. 时间设置选“自定义时间”：`2024-01-01` 至 `2024-03-31`。
5. 代码设置选“代码选择”，加入：

```text
000001
000002
600000
600519
300750
```

6. 字段选择至少勾选：

- 股票代码、公司简称
- 新闻 ID
- 新闻标题
- 报道时间
- 报道媒体
- 来源媒体
- 新闻情感
- 是否原创
- 采集网址
- 标题是否提及公司
- 正文提及次数/句子数
- 行业名称、行业代码
- 正文全文或正文内容（如果该表提供）
- 数据采集时间、入库时间、更新时间（如果提供）

7. 条件设置先留空。
8. 格式设置选择 CSV。
9. 点击“预览”。CNRDS 通常只显示前 100 条。
10. 确认后点击“下载”。
11. 在下载概要页再次检查条件，点击 **“添加到下载列表”**。
12. 回到页面顶部，点击 **“下载列表”**。
13. 找到刚才的任务，点击下载图标保存文件。

文件名：

```text
CNRDS_CFND_NEWS_BASIC_SAMPLE_2024Q1.csv
```

### 10.3 再下“按交易时间统计”

在同一个库中选择：

```text
网络财经新闻
→ 网络财经新闻量化统计（按交易时间）
```

勾选全部与时间段、交易时段、正中负新闻数量有关的字段。这个表适合构造每天收盘前后新闻强度，但它通常没有原文。

文件名：

```text
CNRDS_CFND_NEWS_TRADING_TIME_SAMPLE_2024Q1.csv
```

### 10.4 下载股吧小样本

1. 顶部搜索：

```text
股吧评论数据库
```

2. 进入常见简称带 `GUBA` 的数据库。
3. 优先寻找“股吧文章/帖子基本信息”“股吧评论基本信息”一类原始记录表。
4. 如果学校权限只有统计表，选择：

```text
股吧文章统计（交易时间）
```

或：

```text
股吧文章统计（自然日）
```

5. 日期和代码仍用 2024-01-01 至 2024-03-31、上面 5 只股票。
6. 原始记录表至少选：帖子 ID、股票代码、发布时间、标题、正文、作者匿名 ID、来源、URL、回复关系、采集/入库时间。
7. 统计表至少选：股票代码、统计日期/获取时间、时间段、是否交易时段、帖子总量、正负中性数量、阅读数、评论数。
8. 按 CNRDS 的“预览 → 下载概要 → 添加到下载列表 → 顶部下载列表”流程保存。

文件名：

```text
CNRDS_GUBA_RAW_SAMPLE_2024Q1.csv
```

如果只有统计数据：

```text
CNRDS_GUBA_TRADING_TIME_SAMPLE_2024Q1.csv
```

### 10.5 这里有一个非常重要的判断

CNRDS 某些新闻表提供标题、情绪、媒体、URL和统计量，但不一定提供完整正文。某些股吧库也可能只提供按日统计。

- 有 `正文/帖子内容`：可以作为 AI 原文候选。
- 只有标题：可以做标题模型，但要标记“无正文”。
- 只有正负面数量：只能作为结构化情绪因子，不能伪装成原文。
- 没有首次采集/入库时间：历史回测存在时间可得性风险，要在说明中记录，文本收益权重先保持关闭。

### 10.6 CNRDS 全量怎么拆

样本通过后，从 2015 年开始按“数据库 + 表 + 年”下载：

```text
CNRDS_CFND_NEWS_BASIC_2015.csv
CNRDS_CFND_NEWS_TRADING_TIME_2015.csv
CNRDS_GUBA_RAW_2015.csv
...
```

如果单年仍超过授权下载上限，再按季度拆成 `2015Q1`、`2015Q2`、`2015Q3`、`2015Q4`。

股票范围优先为历史沪深300成分并集。没有代码清单时先不要选择今天的300只；等 Wind 历史成员表确认后再导入代码模板。

## 十一、WinGo：上市公司报告和公告文本怎么下

WinGo 适合获取定期报告、董事会报告、管理层讨论与分析、审计报告、内控报告、社会责任报告、招股说明书、业绩说明会等文本和文本指标。

### 11.1 进入 WinGo

1. 打开[清华 WinGo 说明页](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021558927003966)。
2. 点击“访问入口”。
3. 进入 `wingodata.com` 后，找 **“签约机构免密登录”**、机构登录或个人登录。
4. 如果要求个人账号，使用清华邮箱注册并在“个人中心 → 认证邮箱”完成认证。
5. 如果页面只允许预览 2 条、要求按数据点付费，说明当前账号没有识别到机构权限。不要立即付款，先从清华入口重新进入，再联系图书馆。

### 11.2 下载 5 只股票文本样本

页面菜单名称可能因版本调整，按下面的中文词找：

```text
中国上市公司文本数据库
→ 中国上市公司文本
```

设置：

```text
股票：000001、000002、600000、600519、300750
报告年度：2023、2024
报告类型：年度报告、季度报告、审计报告、内部控制评价报告
```

如果有“报告期末”和“报告年度”两个条件，两个都要核对：年度报告的报告期末通常是 12 月 31 日，但披露发生在下一年。

先找并下载“基本信息表”或原始文本，选择：

- 股票代码和公司名称
- 文档/报告 ID
- 报告标题
- 报告类型
- 报告期末
- 公告/披露日期和时间
- 原始文件 URL
- 文本正文或原始文档
- 数据入库/更新时间

操作通常是：

1. 选择股票代码；
2. 选择年份；
3. 选择报告类型；
4. 点击查询；
5. 预览结果；
6. 点击“结果下载”或“下载”；
7. 阅读第一步“数据下载须知”；
8. 选择下载文件内容和格式；
9. 确认发送到绑定邮箱；
10. 收到邮件后立即下载并保存。

WinGo 当前界面提示下载结果只保存有限时间，常见为 15 天。收到链接后不要拖延。

文件名：

```text
WINGO_LISTED_COMPANY_TEXT_SAMPLE_2023_2024.zip
WINGO_LISTED_COMPANY_TEXT_SAMPLE_2023_2024__基本信息.csv
```

### 11.3 “词频”和“文本特征”先不要全买

WinGo 有词频、相似词、文本特征、自定义特征和会计金融指标。第一步优先拿原文和基础信息，因为我们自己的 AI 管线要保留原文、时间和证据。

如果学校权限已经包含文本特征，可以另外下一个样本，字段包括可读性、语气、风险、不确定性等，并记录指标定义。不要在尚未确认机构权限时购买个人数据点。

### 11.4 如果 WinGo 没有公告正文

使用[RESSET财经文本智能分析平台](https://rtas.resset.com/)作为替代：

1. 从清华 RESSET 入口完成机构认证。
2. 进入财经文本智能分析平台。
3. 在文本类型中找“上市公司公告”“定期报告”“审计报告”“互动平台”等。
4. 仍先用 5 只股票、2024 年一小段时间。
5. 下载标题、代码、原始发布时间、原文、来源、URL、入库时间和文档 ID。
6. 如果平台只能在线分析、不能批量导出原文，向平台“咨询反馈”提交下面第十三节的请求文本。

## 十二、朝阳永续：分析师预测和一致预期怎么下

这一部分最容易误下成“今天的最新预测”。我们要的是**每一个历史时点当时看到的预测**。

### 12.1 先判断清华给你的是哪种入口

清华订购列表包含：

- [Go-Goal 金融终端](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021798414603966)
- [一致预期基础数据库](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021962908703966)
- [一致预期数据衍生库](https://ecollection.lib.tsinghua.edu.cn/databasenav/entrance/detail?mmsid=991021962908003966)

点击访问入口后，可能出现三种情况：

1. **网页查询界面**：按代码、日期和字段查询后导出。
2. **Go-Goal 客户端/Excel 插件**：需要在指定电脑或安装插件后导出。
3. **数据库 SDK/SQL 说明页**：需要馆员提供服务器、只读账号、SDK或连接配置。

第三种不是你不会操作，而是它本来就不是普通网页下载。直接联系馆员拿连接说明。

### 12.2 先下载 5 只股票的一年样本

无论是网页、客户端还是 Excel 插件，搜索下面这些词：

```text
卖方预测数据
盈利预测基础数据库
个股一致预期
一致预期评级
盈利预测调整
```

样本范围：

```text
股票：000001、000002、600000、600519、300750
统计/报告日期：2024-01-01 至 2024-12-31
预测年度：2024、2025、2026
```

先下分析师层面的原始预测，至少包括：

- 股票代码、股票名称
- 报告 ID
- 报告发布日期和时间
- 券商/研究机构
- 分析师 ID 和姓名
- 预测年度
- 营业收入预测
- 归母净利润预测
- EPS 预测
- 评级及评级变化
- 目标价及目标价变化
- 数据首次入库时间、最后更新时间
- 报告撤回/修订/有效状态

再下每日一致预期，至少包括：

- 股票代码
- 一致预期日期
- 一致预期年度
- 一致预期营业收入
- 一致预期净利润
- 一致预期 EPS
- 覆盖机构/分析师数量
- 均值、中位数、标准差或分歧度（如有）
- 1/4/13/26/52 周前的历史值或修正率（如有）
- 入库时间、更新时间

朝阳永续技术字典中常见的表名包括：

```text
rpt_forecast_stk     卖方预测数据
con_forecast_stk     个股一致预期
con_rating_stk       个股一致预期评级
```

表名可能因学校部署版本不同，以页面数据字典为准。

文件名：

```text
GOGOAL_SELLSIDE_FORECAST_SAMPLE_2024.csv
GOGOAL_CONSENSUS_DAILY_SAMPLE_2024.csv
GOGOAL_DATA_DICTIONARY.pdf
```

### 12.3 必须检查是不是“历史时点”

打开一致预期样本，检查同一股票是否有很多个不同的“一致预期日期”。

- 有每天/每周的历史日期：方向正确。
- 每只股票只有一行，而且日期都是今天：这是当前快照，不能回测。
- 历史日期很多，但每行数值都等于今天：可能发生了历史回填，必须向供应商确认。

### 12.4 需要馆员帮助时，复制这段话

```text
老师您好，我在做非商业学术用途的A股历史回测，需要使用清华已购的
朝阳永续盈利预测基础数据库和一致预期衍生库。

我需要的是历史时点数据，不是当前最新快照，范围为2010年至今，字段包括：
股票代码、报告ID、券商、分析师、报告日期、预测年度、收入/净利润/EPS预测、
评级、目标价、修订或撤回状态、入库时间；以及每日个股一致预期、覆盖人数和分歧度。

请问学校授权的使用方式是网页、Go-Goal客户端、Excel插件还是SQL/SDK？
如为SQL/SDK，请提供安装包、服务器地址、端口、库名、只读账号获取方式和数据字典。
如网页只能看当前截面，请问如何正式批量导出历史时点数据？
```

### 12.5 全量怎么拆

样本确认后：

- 卖方原始预测按报告年份拆分；
- 一致预期按统计年份拆分；
- 股票范围用历史沪深300成分并集；
- 2010 年至今；
- 保留原始预测和调整记录；
- 不用今天的预测覆盖历史。

文件名示例：

```text
GOGOAL_SELLSIDE_FORECAST_2010.csv
GOGOAL_CONSENSUS_DAILY_2010.csv
...
```

## 十三、政策文本怎么准备

第一版先做公司公告、新闻和股吧，政策文本放在第二批。政策源优先使用有明确发布时间和原文链接的授权库，例如知领政策库、威科、律商，以及政府官方网站。

进入政策库后按以下条件筛选：

- 发布时间：2015年至今；
- 发布部门：国务院、发改委、财政部、人民银行、证监会、工信部等；
- 政策层级：中央优先，行业关键地方政策补充；
- 主题：金融监管、资本市场、货币财政、房地产、能源、医药、科技、汽车、消费、环保等；
- 文档类型：法律、行政法规、部门规章、规范性文件、通知、意见、规划。

每篇至少保留：

- 文档 ID
- 标题
- 发布部门
- 原始发布日期和时间
- 生效日期
- 原文正文
- 原文 URL
- 适用地区
- 政策层级
- 主题/行业标签
- 数据库首次收录或更新时间

政策到股票的映射后续由 AI 做，但原始下载时不要为了方便就只保留数据库自动推荐的几只股票。

## 十四、第二阶段：RESSET 高频和集合竞价

结构化日频模型稳定后再下载这部分，不要现在先做。

通过清华的 RESSET 高频基础版/增强版入口进入，搜索：

```text
集合竞价
竞价快照
逐笔委托
逐笔成交
1分钟行情
```

第一轮只要近 3 年、历史沪深300成分，优先：

- 09:15—09:25 集合竞价快照；
- 09:25 集合竞价结果；
- 09:30—10:00 的 1 分钟开高低收、成交量额；
- 买卖盘价格和数量（如权限有）；
- 当日涨跌停价、停牌状态；
- 精确到秒或毫秒的时间戳和时区。

如果入口要求安装专用客户端或只能在校内服务器使用，向馆员说：

```text
我需要锐思高频库中近3年的A股集合竞价和开盘后30分钟1分钟行情，
用于非商业学术回测。请提供学校授权客户端、安装说明、导出上限和字段字典。
```

## 十五、每次下载完成后的固定动作

每个文件都按下面顺序处理：

1. 保存到对应数据库的 `SAMPLE` 或 `FULL` 文件夹。
2. 立即改成有意义的英文文件名；不要保留十几个 `download(1).zip`。
3. 保留原始 ZIP。
4. 解压后的原始文件不要改。
5. 同时保存数据字典、字段说明和查询截图。
6. 新建 `__说明.txt`，记录数据库、表名、日期、代码、字段、单位和筛选条件。
7. 检查股票代码前导 0。
8. 检查日期范围。
9. 检查是否只有当前存续股票。
10. 检查是否误用了今天的成分或一致预期回填历史。

## 十六、你看到这些情况时该怎么办

### 情况 A：网页又让我付费

先退出，不付款。重新从清华数据库说明页的“访问入口”进入。仍要求付费，就联系说明页上的责任馆员，说明“机构权限未识别”。

### 情况 B：表是灰色的，或没有下载按钮

这是权限问题，不是操作问题。记录数据库名、表名和页面提示，联系图书馆确认清华是否订购了该子库。

### 情况 C：一次下载超过上限

先按年拆，再按季度拆。仍需要大量任务时，申请供应商的正式批量导出、数据服务或只读数据库访问。不要自动化点击网页。

### 情况 D：只看得到最新 300 只沪深300成分

停止。这不是历史成分。继续搜索“历史成分、纳入日期、剔除日期、成分调整”；没有就向 Wind 馆员申请历史表。

### 情况 E：财务表没有公告日期

三张报表先保留，另搜“实际披露日期/财务报告披露日期”。不要把报告期末当作可用时间。

### 情况 F：新闻没有正文

保留标题、ID、时间、来源、URL和情绪；在说明中写“无正文”。再从 WinGo、锐思文本或公告库补原文。

### 情况 G：CSV 打开后中文乱码

不要覆盖原文件。用 Excel 的“数据 → 从文本/CSV”重新导入，编码依次尝试 UTF-8、GB18030/GBK。把实际编码写入说明文件。

### 情况 H：不知道应该选哪个相似字段

不要猜。点“字段说明/数据词典”，保存截图或字典。把两个候选字段都下载在小样本里，后续对账后再决定。

## 十八、这些原始数据将怎样变成产品输入

下载的供应商文件不会直接丢进 `data/inbox`。后续处理顺序是：

```text
原始文件 data/raw
→ 字段和单位核对
→ 股票代码统一为 600000.SH / 000001.SZ
→ 日期和时区统一
→ 历史成分展开
→ 财务披露时间做 PIT 对齐
→ 新闻/公告去重并保留三种时间
→ 生成 data/inbox 标准表
→ 运行数据校验
→ 真实历史回测
```

项目标准表的精确列名和研究口径仍以[数据下载清单](数据下载清单.md)为准。这份手册负责告诉你“在数据库里怎么拿到原始文件”，数据下载清单负责告诉我们“清洗后必须长什么样”。
