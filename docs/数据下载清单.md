# A share investment：给学校数据库的下载清单

> 历史结构化数据已经完成。本文件保留正式字段口径，供以后增量更新或重新导出时核对；当前实际缺口见 [剩余必需数据](剩余必需数据.md)。

设定：A股，历史沪深300股票池，每日收盘后评分、默认周频调仓，次日开盘条件交易；模拟本金 **100,000 元**，目标持有 15 只。产品目录 `A share investment`，标准数据放入 `data/inbox`。

## 股票范围：最容易出错的部分

- 要“**研究期间每个历史时点的沪深300成分**”，不能只下载今天的300只并回溯。
- 先导出历史成分变更清单，取历次成分并集，再下载这些证券的完整上市期行情，至少覆盖入选前一年。退出成分后仍需行情，直到历史持仓能退出；退市股票不能消失。
- 更稳妥的学校批量导出是全A股历史行情 + 历史沪深300成分表。引擎只在当时的沪深300内选股。
- 行业分类、ST、上市天数、流通市值、可交易权限也必须是当时值。
- 沪深300包含不同板块。不能把所有股票统一视作100股起买，也不能永久写死ST涨跌幅。2026年的交易规则已有修订，模型直接使用数据中的当日涨跌停价及最小申报数量。[上交所2026交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)

## 第一版引擎实际接收的标准表

支持UTF-8 CSV或Parquet，一个表一个文件，例如 `prices.parquet`。不要同时放同名CSV和Parquet；命令行读取时Parquet优先。界面导入会替换另一格式，避免旧数据混用。时间统一 Asia/Shanghai；可以明确带 `+08:00`。

股票代码使用带交易所的字符串，例如 `600000.SH`、`000001.SZ`。金额单位**人民币元**；成交量**股**；比率**小数**（5%=0.05）；成交额不得混入万元，市值不得混入亿元。保留缺失值，不用0冒充未知。

### 1. calendar.csv：交易日历

`date`：真实开市交易日，YYYY-MM-DD，一天一行。包括未来至少10个开市日。**工作日不等于交易日**，不能用排除周末的日历做实盘计划。

### 2. prices.csv：一只股票一个交易日一行

| 字段 | 含义 / 要求 |
|---|---|
| date, symbol | 交易日期、证券唯一代码 |
| open, high, low, close | 未复权开高低收；停牌日提供持仓估值所需收盘价及停牌标识 |
| prev_close | 当日交易所口径昨收/除权参考价，按供应商说明 |
| volume, amount | 成交股数、成交金额（元）；停牌日0可接受 |
| adj_factor | 日度累计复权因子，约定 `未复权价 × adj_factor` 构成连续收益价格；需附供应商公式，不可随便混用前复权价 |
| upper_limit, lower_limit | 当日实际涨跌停价格；确属无价格限制的日子可空，未知不能冒充无限制 |
| suspended, is_st | 当时停牌、风险警示状态；0或1 |
| market_cap, float_market_cap | 当日总市值、流通市值（元） |
| turnover_rate | 当日换手率，小数；注明流通股分母 |
| industry | 当时一级行业，同一版本分类体系；建议申万一级，保留体系版本 |
| min_order, lot_step | 最低普通申报数量及递增单位。主板常见100/100；科创板限价申报常见200/1。特殊卖出尾数由执行层处理 |
| listed_days | 截至当日已上市的交易日数量 |
| available_at | 此行信息最早可用于交易研究的时间，例如供应商确实已交付的当日15:30；不能把实际晚到数据改成15:30 |

需要下载原始历史价格和公司行动，即使标签使用复权收益，现金账户仍按未复权成交价计账。

### 3. universe.csv：逐日历史成分

`date, symbol, weight, known_at`。weight为小数、逐日合计约1；known_at为该成分信息当时已公开/可知的时间，必须不晚于信号截止时刻。

如果数据库只能导出“纳入生效日、剔除生效日、公告日”，先保留原表和字段说明，后续展开成逐日成分。不要自行凭今天的代码名单填满历史。

### 4. fundamentals.csv：PIT财务快照

`symbol, report_period, available_at, revenue_ttm, net_profit_ttm, book_equity, operating_cashflow_ttm, total_assets, total_liabilities, roe, gross_margin, revenue_growth, profit_growth`。

- report_period为报告期末，**不是可用时间**。
- available_at为当时已公开且你能取得的最早时间；财报只有日期、没有时分秒时，保守设为该日23:59:59，使午夜生成的信号不提前使用。需在数据来源说明中记录这一假设。
- 保留每次修订的版本。更正后的数值只从更正公告可用时起使用，不改写此前历史。
- TTM金额需用当时已知季度数据计算，不能拿今天数据商重新计算的TTM覆盖当时值。
- 同时导出原始三张报表以便核对。金融股的毛利率等指标可能无意义，保留缺失，后续可按行业建模；第一版有缺失率筛选。
- ROE、增长、毛利率均小数；费用/收入负值、净利润为负可保留，不要人为删除亏损公司。

### 5. benchmark.csv：对照基准

`date, close, total_return_close`。价格指数和全收益指数均来自数据商；若仅有价格指数，先补齐全收益指数，不把两个混标。回测使用全收益指数归一化比较。

### 6. actions.csv：公司行动

`date, symbol, share_multiplier, cash_per_share, known_at`。date是持仓应调整的除权除息日；股数乘数（不送转为1）、每股现金（不分红为0）、公告可知时间。无公司行动时提供同表头空表。

**第一版限制：**实现现金股利与普通送转股；现金在除息日计入可用现金，没有模拟实际到账日、红利税、配股认购、复杂重组和退市结算。为了避免错误，应从回测评估区间剔除无法正确计账的复杂案例或先扩充执行器，不能用本版本给这些案例贴实盘就绪标签。成交计划遇除权日取消旧价格订单，次日重新生成。

### 7. fees.csv：历史税费

`start_date, end_date, sell_stamp_rate, transfer_rate`。区间闭区间，日期完整覆盖、互不重叠。卖出印花税只卖出收取；过户费双边。券商佣金/最低费用另设在策略参数。

证券交易印花税自2023-08-28实施减半，历史测试不能整段都按今天费率。[税务部门公告](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1780448)

演示包内0.0005/0.00001仅为**合成数据成本示例**；真实历史需要完整费率区间与账户实际收费，不能原封不动复制演示费率表。

### 8. documents.csv：非结构化原文

`document_id, symbol, source_type, source_url, published_at, first_seen_at, title, text`。

- source_type取filing/policy/news/forum。正文完整，保留标题、原始编码和文档ID。
- published_at是最初发表时间；first_seen_at是供应商/本系统首次收录时间。网页“最后更新”不能当最初发表时间。
- 宏观政策先保留原文及行业关联证据，再映射证券；当前抽取接口一条记录对应一只证券。多股票公告/政策可拆分多条，ID需唯一，避免只按股票简称误匹配。
- 论坛的浏览、点赞、回复不能使用后来累计到今天的数量预测旧日期。现版本未把这些字段投入模型。
- 本地RSS采集器只处理明确指定的单个允许抓取的RSS源；学校付费库优先用授权导出/API。未内置需要账号、绕过登录或反爬的采集。

### 9. events.csv：事件结果

见模板完整字段，包括事件类别、方向、重要性、置信度、新颖度、来源、原文逐字证据、三种时间、模型/提示词版本及内容哈希。

引擎使用 `max(published_at, first_seen_at, processed_at)` 作为事件可用时间，并基于证券+内容哈希去重。新抽取结果的 processed_at 是实际现在时间。**不得为了得到历史收益把它改成文章发表时间**。数据商历史事件标签须有当时生成标签的证据。后验用最新LLM重放旧新闻，只能作为带污染风险的探索；不能替代冻结模型后的前向模拟。当前产品不提供伪造处理时间的“历史重放”开关。

### 10. holdings.csv + account.json：自己的模拟或实际账户快照

持仓表：`symbol, shares, sellable_shares, cost_price`。另创建：

```json
{"as_of":"2026-09-10","cash":35000.0}
```

as_of必须与本次信号日收盘一致。cash是真正剩余现金，**不是初始本金**。没有账户文件时，计划使用配置的10万元全现金模拟账户；有持仓却无现金快照则停止。回测始终从模拟初始现金开始，不把今天持仓穿越到历史。

### 11. auction.csv：开盘前价格检查

`date, symbol, indicative_open, upper_limit, lower_limit, suspended, available_at`。

09:20–09:30期间的有效快照；优先09:25实际集合竞价结果。预检仅检查价格条件、停牌与可卖数量；尚需实际账户现金、权限、公司行动与券商订单状态。日线不提供竞价排队量，不会把“触及涨停仍买到”写成确定成交。

## 请同时提供的数据说明

每批保留：数据库名称/模块、导出时间、筛选条件、证券范围、字段字典、单位、复权方法、时区、是否修订后版本、缺失值规则。原始文件和清洗结果分开保存。所有运行会记录输入文件SHA256。

大文件按年份/表拆分导出即可，先不用手工拼接。产品直接输入为规范后的单表CSV/Parquet，提供了列映射及单位换算工具；不认识的供应商字段不会自动猜测。

## 第二阶段值得研究但尚未实现的因子

一致预期修正/分歧、盈利惊喜、行业相对质量价值、行业/市值残差化、政策暴露的实体关系图、供应链传导、文本嵌入新颖度、论坛异常关注度、空头/拥挤代理、分钟执行。优先按成本后样本外增量排序，逐项做消融实验。

CRSP、北美Compustat、IBES全球数据、BvD、私募通等暂时不是这个A股日频框架的首批下载对象。你有这些资源，并不意味着全部都需要接入。
