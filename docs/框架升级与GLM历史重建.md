# 框架升级与GLM历史重建

本地研究区间：2026-09-15至2026-11-16；初始资金100万元。

## 两种实验必须区分

- 严格时间记录模拟：事件的发布时间、首次抓取时间、处理时间都必须不晚于决策时点。
- 历史事件重建：今天补抓历史原文，按原始发布时间在各历史决策日筛选，让今天的GLM重新抽取。真实抓取和处理时间保留，不修改成历史日期。提示词禁止使用后续信息，但不能证明模型训练记忆没有未来信息。因此只用于探索性研究。

模型实际未产生合格事件时，不发布“GLM占30%”的收益。没有原文不能靠把设置改成30%制造事件信号。

## 当前输入与限制

已保存5,101篇历史公告的检索记录、17,138条新闻检索摘要。首批候选包含977篇公告与494条新闻摘要。545篇公告成功提取最多前8页、最多22,000字符的PDF内容，其余432篇只有标题。送给模型的每篇输入上限8,000字符。标题、摘要和PDF摘录有明确scope，不能称作完整全文。历史论坛全文未取得，不以当前热度补历史。

首批公告按日期和实质性事件关键词确定优先级，每个自然日最多20篇；新闻最多8条/日。该抽样不使用后续收益，但覆盖并不完整。之后可扩大预算或接入授权历史文本库。

## GLM评估表

只输出结构化字段与原文证据：事实摘要、事件类别、方向、重要性、置信度、新颖度、影响业务、持续天数、风险标记。超预期程度只有在输入存在可核验预期时填写；价格是否已反应只有在输入提供截至当时的价格证据时填写，其余为null。不要求输出内部思维链。

实际未来决策仍有三重时间闸门。历史重建单独保存，不能混进实时事件账本。

## 因子模型与组合

XGBoost rank:pairwise学习23个量价/基本面因子和83个独立WorldQuant因子，共106项；按信号日滚动训练，训练只含已成熟标签，并沿用时间隔离。每20个交易日重训一次。深度3、120棵树、较强正则化；参数不按本段收益反复择优。

若历史GLM批次成功，综合分数 = 70% × XGBoost横截面排名 + 30% × 事件分数，再转换为百分位排名。重建实验中没有可用事件的股票以50分为中性：这是缺失信息下的建模约定，不代表确实没有事件。批次认证失败或网络失败则拒绝发布完整事件回测。

每日评分、下一交易日开盘调仓；目标10只。原持仓在前15名且仍符合筛选时可保留，空位由排名补齐；双边换手上限60%、最多15笔，整手、现金、T+1、价格限制与佣金滑点继续约束。该缓冲是降低交易的规则选择，尚不能证明提高收益。

## 数据修复

备用源使用真实资产负债表、利润表和现金流量表金额；TTM = 去年全年 + 本年累计 - 去年同期。可用时间取不早于披露/更新日期的保守时间。缺字段保留缺失，不用估算金额伪装为报告值。

分红送转来源为公开分红明细，每10股的金额与股份比例换算为每股；与未复权行情的除权参考价在两分钱内核对才恢复价格。未核对者继续隔离。研究修复集与原始导出、既有报告分开保存。

## 密钥恢复后续跑

在本机.env修复AI_API_KEY后，在项目目录执行：

```bash
.venv/bin/python scripts/run_ai_reconstruction.py
```

该命令先核验GLM认证，再使用已下载材料和已成功GLM缓存完成评分，生成新回测报告。不会把密钥打印到日志。状态保存在data/reconstruction/20260915-20261116/status.json。原文、模型输出和模拟账户不提交Git。
