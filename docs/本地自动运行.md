# 本地自动运行

产品内置调度已开启：北京时间每天00:00处理最近一个已结束交易日。使用交易日历与同日幂等记录；没有新交易日时不重复计划，当天失败不自动重试。网页开关关闭后不再启动新任务。

服务由独立后台进程运行，关闭浏览器和启动它的终端不会停止服务。电脑需要开机、保持联网；睡眠或关机会中断执行。电脑重新启动后，双击项目中的“启动工作台.command”恢复后台服务。

本次未安装登录自启：macOS不允许LaunchAgent直接读取Documents项目目录，失败自启项已移除。

日志：runs/local-service.stdout.log与runs/local-service.stderr.log。进程号仅作诊断，保存在runs/local-service.pid。实际运行状态以本地/api/health与页面状态为准。该机制不依赖Codex定时任务。
