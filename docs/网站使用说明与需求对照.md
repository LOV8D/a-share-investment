# A share investment：网站使用说明与需求对照

更新日期：2026-09-22。本说明按**目前实际运行的版本**写。它是沪深300的研究与模拟盘工作台，输出的是次一交易日的**条件交易计划**；没有连接券商，也不会替你买卖股票。

## 一分钟看懂它怎么工作

每个交易日收盘后，流程是：

**自动获取最新数据 → 检查是否完整、是否来得及用于当天决策 → 给沪深300股票评分 → 考虑10万元资金、整手和交易成本 → 保存次日条件计划 → 在后续运行中用实际观察到的开盘价推进模拟账户。**

两套数据分开存放：你从学校数据库下载的 CSMAR、RESSET 历史数据，固定用于截至 **2026-08-31** 的结构化研究和回测；从 **2026-09-01** 起自动抓取的公开数据用于前向模拟。新数据不会悄悄改写旧回测的收益和回撤。

产品调度器在北京时间每天 **00:00** 尝试一次，处理最近一个已结束的交易日。碰上节假日、最新行情尚未到齐或同一信号日已处理时，不会硬造新计划；成功或失败后当天都不再自动重试，修复问题后可以手动点击“生成每日计划”。

## 怎么打开、每天看什么

1. 在浏览器打开 <https://49.233.170.147/>，用户名输入 `investor`。密码是首次部署时在服务器随机生成的：在这台 Mac 上双击项目中的 `查看云端登录信息.command` 读取；这里不保存或展示密码。当前 IP 使用内部签发证书，浏览器第一次打开可能提示证书不受信任。网页顶端数据源选 **“我的真实数据”**，不要把“合成演示数据”的结果当真实研究。
2. 每天晚上任务完成后或次日早上，先看 **收盘决策台** 的“收盘日期”“下个交易日”和“前向模拟”标记；检查日期是不是你期待的最近一个交易日，以及“当前需要关注”有没有警告。没见到当天数据时，到 **数据中心** 看采集状态和行情覆盖率。
3. 再看 **次日交易计划** 的“仅对某日有效”和“开盘条件订单”。有单时看买/卖方向、代码、股数、计划限价、估算费用和生效条件；需要留存就点 **导出订单 CSV** 或 **导出完整计划**。**待开盘预检**不表示可以直接无条件下单，买单也可能依赖卖单成交。过了计划对应的开盘时间，这张计划不能顺延到后一天。
4. 没有订单也可能一切正常：默认每天评分、**仅在本周最后一个交易日收盘后**为下一交易日生成调仓订单；即使到了调仓日，整手、现金、行业上限和最低有效交易额也可能使订单数为零。看页面给出的原因，不要为了凑数强行买入。
5. 模拟盘后续运行会把上次条件计划按观察到的开盘价、停牌/涨跌停、现金、T+1和费用规则尝试入账；网页的模拟资金随之更新。它是日线模型估计的模拟成交，不能证明真实账户按相同价格成交。**你不需要每天手工从学校数据库下载增量行情。**

若只想在这台 Mac 上查看本地副本，可以双击 `启动工作台.command`，再打开 <http://127.0.0.1:8765>。本地与云端各有自己的运行文件；持续的云端模拟账户以**云服务器上的状态**为准，不能把本地新结果误认成云端已成交记录。

## 六个页面分别管什么

| 页面 | 你看什么、可以做什么 | 容易误解的地方 |
|---|---|---|
| 收盘决策台 | 最新信号日、下个交易日、模拟账户净值、目标持仓数、条件订单数、前8名和警告。需要手动补跑时可按“生成每日计划”；点“查看历史回测”会打开已保存的研究结果。 | 平时由云端自动运行，不用每天手按。同一信号日、参数未变时点击会提示“已生成”，不会重复抓数。页面上的“冻结历史研究净值”**不是**当前10万元模拟账户的净值曲线；采集失败会持续显示提醒，旧计划不会顺延。 |
| 次日交易计划 | 查看当日全体候选、目标持仓、资金不足/排除原因、计划生效条件；可导出 `orders.csv`、`plan.json`。点“因子解释”看个股详情。 | 个股弹窗里的 LightGBM 特征贡献解释的是**挑战者模型**，不是生产分数的因果解释。订单是条件计划，不是券商委托或已成交。 |
| 因子与回测 | 直接查看云端保存的冻结历史研究：收益、回撤、基准、成本压力测试、因子诊断、ML对照和模型卡。 | 这页只读取已完成的历史研究，不会在2GB云服务器重新计算，也不改变最新前向模拟报告。若报告没有成功上传，会明确显示“历史研究报告暂时不可用”。 |
| AI 事件观察 | 浏览抓到的公告、新闻、政策和论坛材料，以及来源、时间、原文证据和事件详情。 | 目前文本**不影响买卖**；未配置实际文本抽取模型时，不能把原文采集等同于 AI 已经评判新闻。某一文本源失败会留警告。 |
| 数据中心 | 确认历史数据已通过校验、冻结截止日、最新前向信号日、300只成分、行情覆盖率、来源和错误。可按“立即采集并校验”。 | “立即采集”只采数据，**不等于生成新计划**；“重新校验历史库”刷新校验显示。网页也允许导入文件，但随意上传可能覆盖该服务器的同名历史表，日常使用不要上传。 |
| 策略参数 | 查看/保存模拟资金、目标持仓数、交易成本、仓位限制、调仓频率和实验性文本开关。 | 改参数只影响后续运行，不会重算已有历史报告，也不会自动重置现有模拟账户。页面“每日自动运行”开关同时控制本地内置调度器和云端独立调度器。 |

所有页面顶部都可以看数据源。报告上的 **“合成演示”** 是测试数据，**“真实数据研究”** 是历史回测，**“前向模拟”** 才是自动采集后的模拟盘日报；先看这个标记再读数字。

**历史图与模拟盘为何分开？** 每晚前向日报只计算当天评分和次日条件计划，不会重跑2010—2026年的历史回测。网站现在从独立保存的冻结研究报告读取历史净值图、收益/回撤、因子诊断和ML对照；最新前向日期和账户仍单独更新。前向模拟账户自身的连续净值图目前尚未接好，需要积累模拟记录并单独开发展示。若当天官方数据源中断，“生成每日计划”会保留上次成功报告并持续提示失败原因，不会把过期订单冒充为今天的新订单。

## 分数和回测应该怎样理解

生产分数由价值、质量、低风险和短期反转的当日横截面排名组成，最终显示为0—100的**相对评分**，不是“上涨概率”或承诺收益。模型用当时已能看到的财务和行情；没有实际披露日期的历史财报暂按**法定披露截止日次日**才可使用，因而可能少用一段早已公开的信息。选股后按逆波动和持仓约束分配，再按整手、现金、费用和交易限制生成条件订单。

已完成的历史结构化研究覆盖 **2010-05-31—2026-08-31**：扣除模拟成本后年化收益 **6.45%**，沪深300全收益基准 **5.70%**；最大回撤 **26.9%**，基准 **46.1%**。但这整段历史也参与过模型失败排查、规则和参数选择，**不是未碰过的最终检验样本**，更不能据此断言真实投资会赚钱。前向模拟至少还要积累60个交易日，并与只有结构化分数的基线比较，才能判断 ML 或文本能否真正增加收益。

当前**没有连接券商、没有真实自动成交、没有09:25定时竞价预检**。模拟开盘成交由日线开盘价和固定滑点近似，遇到集合竞价排队、复杂公司行动、退市清算或分红到账时可能与现实不同。若准备真的按计划交易，需要先核对最新交易日、个股可交易状态、实际可卖数量、费用和券商规则。

## 出问题时按这个顺序检查

- **日期停在昨天或更早：**先看数据中心“最新前向信号日”和采集状态，再看收盘决策台的警告；节假日、数据尚未更新和任务失败都可能导致日期未前进。不要把旧计划用于新交易日。
- **成分不是300只、行情不全或第二来源价格不一致：**质量闸门会拦截新发布或相关订单；保留上一份成功报告只是便于查看，**不代表旧订单仍然有效**。当天不会自动重跑，可手动运行或等待次日00:00。
- **有评分但没有买卖单：**先检查今天是否本周最后一个交易日，然后看现金、持仓、整手、个股和行业上限、最低有效交易额以及“资金与预算限制”。
- **AI 页没有内容：**看数据中心的文本来源警告；文本缺席不应被解释为“没有相关新闻”，也不会改变当前结构化订单。
- **需要知道云端任务是否真的运行：**详细命令在[腾讯云部署操作手册](腾讯云部署.md)的“每晚自动运行”一节。通常先看网页信号日期，必要时再以服务器调度记录为准。
