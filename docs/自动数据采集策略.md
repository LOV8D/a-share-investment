# 自动数据采集与每晚决策策略

这套策略把学校数据库下载的数据当作**冻结的历史研究底座**，把模拟盘开始后的公开数据放在独立的实时层。历史回测永远截止到 **2026-08-31**；后续新数据只用于前向模拟，不会悄悄改写已经报告过的历史收益与回撤。

## 每个交易日会自动做什么

产品调度器按北京时间每天 **00:00** 尝试一次，处理最近一个已经结束的交易日。交易日历和幂等检查会判断是否真的有新收盘数据；节假日或同一信号日已经成功运行时不重复生成计划。自动任务无论成功或失败，当天都不再重试；失败原因会保留在页面上，用户可以手动生成计划。

一次完整运行的顺序如下：

1. 加任务锁，避免网页按钮和定时任务同时启动两份作业。
2. 查询公开交易日历，确定最近一个已经收盘的交易日。
3. 读取 `data/inbox` 中冻结到 2026-08-31 的历史库，绝不覆盖原文件。
4. 获取最新沪深300官方成分，保存当日成分快照。
5. 用 BaoStock 获取成分股及模拟账户持仓股的未复权日线、停牌/ST状态、成交额、复权因子、分红送转、沪深300指数和未来交易日历。
6. 检查是否有新财报需要更新；只有带实际发布日期且能够完整转换成规范字段的数据才会发布。
7. 抓取公告、关注股票新闻、论坛热度和国务院、证监会、央行、发改委政策网页快照。每条文本保存发布时间和首次抓取时间。
8. 把本次响应先写入不可变的 `data/live/raw/<采集编号>/`，再合并到增量层 `data/live/overlay/`。
9. 运行质量闸门。通过后以原子替换方式发布 `data/live/current/`；中途失败不会留下半套可用数据。
10. 若上一张条件计划的交易日已经到来，按真实观察到的当日开盘价、停牌、涨跌停、现金、整手、费用和 T+1 规则更新模拟账户。
11. 用最近约 756 个交易日训练窗口计算因子和模型挑战者，生成最新排名与次日条件计划。
12. 对所有拟交易股票再用独立行情源核对收盘价。缺失或偏差超过 20bp 时，自动把订单移到阻断区，不允许进入模拟执行队列。
13. 保存运行报告，并把成功信号日写入调度状态，保证当天不会重复下计划。

系统在每个新交易日更新评分并按日生成调仓计划。模拟资金为 100 万元，目标持有最终评分前 10 只，每天最多生成 15 笔买卖操作。

## 数据源与用途

| 数据 | 主来源 | 备用或复核 | 在引擎中的用途 |
|---|---|---|---|
| 沪深300成分与权重 | 中证指数公开接口（由 AKShare 适配） | 最近一次已通过快照 | 当日股票池；拿不到新的官方300只名单时不发布新数据 |
| 股票日线 | BaoStock | 新浪行情（由 AKShare 适配） | 因子、开盘模拟成交、成交额、停牌和涨跌停；订单标的必须通过第二源复核 |
| 沪深300指数 | BaoStock `sh.000300` | 历史 RESSET 基准 | 前向净值参考。公开实时段是价格指数代理，历史回测指标继续使用已冻结的全收益指数 |
| 交易日历 | BaoStock | 新浪交易日历 | 判断最近收盘日、下一交易日和节假日 |
| 分红送转/复权 | BaoStock | 价格缺口检测 | 调整模拟账户股数、成本与现金；发生公司行动的旧条件单自动取消 |
| 财务数据 | BaoStock季度接口 | 冻结的 CSMAR点时财务 | 只接收有发布日期且字段转换完整的新报告；失败时沿用上一期已知数据 |
| 公司公告 | 新浪公告接口（由 AKShare 适配） | 原链接和原始响应快照 | 前向文本观察；默认不影响订单 |
| 股票新闻 | 东方财富新闻接口（由 AKShare 适配） | 原链接和原始响应快照 | 关注持仓与高排名股票，默认不影响订单 |
| 论坛热度 | 东方财富股吧热度接口 | 无 | 仅观察；接口失败只警告，不阻断结构化策略 |
| 政策 | 国务院、证监会、央行、发改委官网 | 页面哈希和HTML快照 | 保存政策证据；行业/个股映射须经可审计抽取后才能使用 |

公开接口可能改版或临时限流，因此原始响应、来源状态和错误都会留档。结构化行情、股票池或交易日历未达到硬门槛时，整次计划失败；新闻、论坛和政策属于观察信号，单独失败不会伪造内容，也不会阻断结构化评分。

## 发布前必须同时满足的条件

- 最新股票池恰好 300 只。
- 300 只成分股最新收盘行情覆盖率为 100%。
- 至少已有 10 个未来交易日。
- 所有规范表通过主键、字段、时间和点时校验。
- 计划日期没有过期。
- 每个拟交易股票的收盘价通过独立来源复核。

任一硬条件失败时，状态写为 `blocked`，上一份成功数据继续保留，但不会把旧计划滚到新日期执行。当天自动任务不会重试；修复数据源后可从网页手动运行，或等待下一天00:00再次尝试。

## 文本和 AI 当前怎么用

历史新闻、政策和论坛不回测。模拟盘从首次抓取当天开始累积文本，保留 `published_at`、`first_seen_at`、原文、来源链接和响应快照。目前 `enable_text_alpha=false`，文本只显示在 AI 事件区，不改变持仓。

以后若配置兼容接口或本地模型，抽取器会要求情绪、重要性、置信度和原文证据；证据不在原文中的结果直接拒绝。至少积累 60 个交易日的前向样本，并证明对结构化基线有稳定增量后，才考虑给文本信号非零权重。

## 文件放在哪里

| 路径 | 内容 |
|---|---|
| `data/inbox/` | 冻结历史研究库，不由实时采集覆盖 |
| `data/live/raw/<采集编号>/` | 每次外部响应与政策网页证据，追加保存 |
| `data/live/overlay/` | 2026-09-01 以后规范化增量 |
| `data/live/current/` | 最近一次通过质量闸门的完整可运行数据 |
| `data/live/collection_status.json` | 最近采集结果、来源和质量闸门状态 |
| `data/live/collection_ledger.jsonl` | 所有采集批次的追加式审计记录 |
| `data/live/paper_state.json` | 100万元模拟账户的现金、持仓、成本和待执行计划 |
| `data/live/paper_executions.parquet` | 已发生的模拟成交与拒单记录 |
| `runs/<运行编号>/` | 每晚排名、计划、订单、模型、配置和来源复核 |

## 日常需要你提供什么

日常模拟盘不再要求手工下载行情、成分、交易日历、公告或新闻。系统会自行采集、校验和留档。

只有下面几项属于后续可选输入：

- 若要让 AI 自动抽取文本，需要一个允许处理这些材料的模型与 API 密钥；不配置时结构化引擎照常运行。
- 若要接近真实成交，需要券商账户只读持仓、真实佣金和 09:25 竞价数据。
- 若将来要自动下单，需要另做券商适配、人工确认和小资金验收；当前产品不会连接券商，也不会真实买卖。
